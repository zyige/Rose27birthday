# Birthday Website

## Files

- `index.html`: The main HTML document that structures the birthday website.
- `styles.css`: Contains the CSS styles for the website, including layout and design.
- `script.js`: JavaScript code that manages the button click event to reveal the hidden message.

## Setup Instructions

1. Clone the repository or download the project files.
2. Open the `index.html` file in your web browser to view the birthday website.
